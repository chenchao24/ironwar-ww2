## 一、新车接入 checklist

按序执行（各步细则见引用文档）：

1. **模型入库**：源 GLB + md 标注放 `tankModel/`；产物输出 `model/`。
   - 部件节点名按 md 标注；**GLTFLoader 剥点 + 空格转下划线**（`interior turret_x` → `interior_turret_x`）
   - 焊死轮系切割：`scripts/split-wheels-td.js <车型>`（CFG 表驱动）——判别式与阈值见
     `docs/wheel-split-playbook.md §十三`，**照做，勿即兴**
2. **装甲板**：armor-editor.html 编辑器定稿 → 整块导出替换 config `armorModel`；
   网格实测轮廓用 `scripts/profile-*.js` 探针辅助
   - ⚠ 炮盾贴近正面墙的车（费迪南/猎豹/猎虎）：plate-hit-test 垂直入射例需偏轴 + 小 yaw
3. **炮弹数据**：按 `docs/炮弹数据设计规范.md`（30° 口径统一、两点拟合、APCR 规则、hePower 分档）
   - **⚠ 9-24 事故**：给炮弹加新字段必须同步 `tank.js fire()` 和 `shell.js fire()` 两处白名单，
     并用端到端实弹脚本验证（单测会漏报）
4. **音源**：`cfg.sound` 字段；循环接缝用 `scripts/analyze-loop-seam.cjs` 波形定标（勿手拍秒数）
5. **config 条目**：caliber/dims/parts/turretPivot/muzzleLocal/exhaustLocal/aiRole/aiTraits/loadout
   —— 枢轴/排气口坐标用 `scripts/measure-*.js` 实测包围盒，**md 坐标系不可直接用**
6. **履带 UV**：`trackScrollAxis` 看 UV 量程判定（纵 V 横 U），底段反向就加 `trackScrollFlip:true`
7. **车库/编队**：TANKS 动态生成，无需手改 UI；tank-display.js 补展示文案
8. **模型瘦身**：`node scripts/optimize-glb.mjs` 跑一遍（产物 `model/opt/`，config 路径指 opt）
9. **回归**：verify-td/verify-new3 + smoke + 对射校验表更新

## 二、新地图接入 checklist

参照阿登（2026-09-28 建成）的最小闭环：

1. **布局数据模块**：新建 `js/mapdata-xxx.js`（纯 JS 无 three 依赖：路网折线/地形参数/出生带/物件点位）
   —— 与 maps.js 建图、核对图脚本同源
2. **maps.js 注册**：`MAPS` 加条目（id/name/size/exposure/terrain/spawns 可选）+ buildMap 分派 +
   `MAP_ROADS` 加路网（小地图底图用）
3. **高度场**：低频大尺度起伏（**勿加高频碎坡**——pitch 采样会拾取坡度尖刺导致上坡掉速）；
   出生带局部放缓；村落压平台地
4. **地形规则**：`config.js TERRAIN_RULES` 加条目（speedK/turnK）；路面提速钩子 `world.roadSpeedAt`
5. **资产分组**：地图专属 GLB 必须进 `main.js _propGroups()` 的分组（common/eu/ard 模式），
   **禁止无条件全载**（懒加载体系，见性能守则）
6. **车库下拉**：index.html `fh-map-select` 加 option（prokhorovka 注释着就是例子）
7. **AI 适配**：POI 由 `generatePOIs` 自动分析（obstacles/sightBlockers），一般无需手改；
   开局接敌过快才动出生带/地图尺寸旋钮
8. **验证**：写 `scripts/xxx-shot.js`（选图→开战→多视角截图+布景统计+0 报错断言）+
   实机 1v3 一局

## 四、素材包接入避坑（Sketchfab GLB 实战坑位）

1. **spec-gloss 旧扩展**：three 0.185 已不支持 `KHR_materials_pbrSpecularGlossiness` 且标 required 会拒载
   → 转换脚本：删 extensionsRequired + diffuse→baseColor、glossiness→roughness（`otherModel/psx_electric_pole_fixed.glb` 即产物，scripts 里有转换代码）
2. **深层嵌套拆分**：`splitTownKit` 只拆到 RootNode 子级；包内再套一层组（如松树包 T1/T2/T3 在
   `Tree_Pine_Snowy` 组里）时，要对子件 `matrixWorld.decompose` 二次反解——**否则丢父链旋转，树躺平**
3. **BLEND 材质**：改 `transparent=false + alphaTest 0.4 + depthWrite true`（密林/卡片防排序错乱）
4. **底面归零 + 平面居中**：包一层 Group，按 Box3 反移（实例化摆放的前置）
5. **贴图烘焙色偏色**：材质 `color` 乘色中和（松树暖黄 ×0x93a8ba 冷蓝灰 即例）
6. **贴图纯白底非 alpha**：剪影卡类素材的"白色背景"是不透明白（treeline 平卡翻车内墙即此坑）

## 五、性能守则（2026-10-08 优化批后新增规矩）

- **新资产懒加载**：车型走 `_ensureTankAssets`，布景走 `_loadPropGroup` 分组——`_load()` 只许装启动最小集
- **新大地图物件必须进空间网格**（destructibles 16m / sightBlockers 32m，注册即入桶，查询已聚集）
- **world.root 下新增静态子件**：会被矩阵冻结——动态件（要每帧动位置的）要么挂 scene 要么保持默认新建对象
- **实测工具**：`node scripts/perf-profile.js`（加载时长/堆/三图 FPS）、`scripts/perf-bench-grid.js`（热路径微基准 A/B）
- **headless FPS 波动 ±15%**：不当验收标准；性能验收用微基准 CPU 时间

## 六、发布流程

### Git（github.com/chenchao24/ironwar-ww2）

```bash
git add -A && git commit -m "说明"
git push origin main
```

- 网络断连是常态：大批量用分批提交 + 断线重试循环（`/tmp/push-retry.sh` 模式，见 10-08 记录）
- **勿在仓库放**：原始大模型（model/*.glb、tankModel/*.glb、EuropeCity 原始件）、`_backup_*/`、截图——.gitignore 已管
- `.gitignore` 不支持行内注释（`pattern   # 注释` 会让规则失效），注释必须独立行（10-08 实坑）

### Cloudflare Pages（ironwar-ww2.pages.dev）

```bash
# 重建部署目录（= git 已提交内容）
rm -rf _deploy && mkdir _deploy && git ls-files -z | xargs -0 -I{} cp --parents {} _deploy/
# 部署（断线自动续传；wrangler 按 .gitignore 跳过文件）
NODE_OPTIONS="--dns-result-order=ipv4first" CLOUDFLARE_API_TOKEN=<token> \
  CLOUDFLARE_ACCOUNT_ID=<id> npx -y wrangler@latest pages deploy _deploy --project-name=ironwar-ww2 --branch=main
```

- **⚠ wrangler 会按 .gitignore 跳文件**——node_modules 被跳过导致线上 three 404（10-08 事故）；
  运行库在 `vendor/three/`（importmap 全部指 vendor，**新增 html 页一律用 ./vendor/three/**）
- 单文件 ≤25MB（Pages 限制）；token 用 API Token（Pages 编辑权限）

### 绿色包（本地分发）

```bash
# 组包（游戏文件剔除开发件）→ 打 zip
# 详见 10-08~09 流程：_package/IronWar3/ = 游戏文件 + bin/node.exe + 启动游戏.bat
tar -a -cf IronWar3-绿色版.zip -C _package IronWar3
```

- **bat 必须 GBK + CRLF**（中文 cmd 编码坑）；node.exe 独立运行时来自 nodejs.org/dist/vXX/win-x64/node.exe
- bat 里写命令**别用脚本转义链生成**（\n 被吃成换行的实坑）；用编辑器直写再转码

## 七、勿踩清单（历次事故）

1. `shell.js fire()` 字段白名单——加炮弹字段同步 tank.js + shell.js 两处（9-23 事故）

4. 无头截图相机矩阵是上一帧的——脚本里 lookAt 后先等一帧再投影取点（9-30 注）

6. 密林炮弹判定：树只倒不挡弹（2026-09-28 用户裁决）；雪灌木/围栏炮弹穿过
