## 0. 背景与目标

### 0.1 现状问题（重构动因）

1. **patrol 全图感知**：无接触 15s 后 AI 直冲玩家真实坐标（`ai.js:144-147`），绕过整个侦查体系。
2. **确认圈过短**：`sightRangeHard=1100m`，AI 对 900m+ 的狙击手无任何确认手段，远距伏击流无敌；同时德军歼击车 1000~1500m 的史实交战距离无法成立。
3. **车型无差异**：轻坦/中坦/重坦/歼击车共用同一套警戒圈与行为参数；黄鼠狼与猎虎视野相同。
4. **阵营无差异**：美英苏德同一套行为。
5. **独狼化**：1vN 时 N 台 AI 各自为战，无分工、无编队、无开火时序，同轴扎堆。
6. **死代码**：`tank.js spotMult()`（车长/通讯员伤亡→索敌倍率）配置齐全但从未接线。
7. **可靠性隐患**：多处状态无超时出口（详见 §8 复核清单）。

### 0.2 设计目标

- 玩家不看血条也能感知差异：德军伏击、苏军冲锋、虎式摆角、黄鼠狼打了就跑。
- 信息驱动：侦查→疑似→确认→交战→失联→搜索，全链路不使用玩家真实坐标。
- 排级协同：1vN 时敌群是一个有角色分工、有阶段节奏的「排」。
- 机制对等：AI 能力上限 = 玩家开同一台车在屏幕上实际能看到/打到的东西；差异只在表现层。
- 可靠兜底：无僵局、无卡死、无假死、无死循环（§8、§9）。

### 0.3 已裁决的边界（讨论结论，不再变更）

| # | 裁决 |
|---|---|
| 1 | 不做「侦查车阵亡→全排降级」机制（敌方编队由玩家自选，未必有侦查车） |
| 2 | 歼击车严格反应式：不预瞄玩家可能路线，只反应已有接触 |
| 3 | 苏军盲射压制：保留，规则见 §4.3 |
| 4 | 阵位系统独立于掩体评分（阵位=掩体+射界+撤离路线三合一） |
| 5 | 本轮不加新玩家机制（烟雾弹/炮兵等另案）；点亮公式重写是双方机制，玩家侧数值面变化点见 §3.12 |
| 6 | ~~地图 `mapSize` 2200→2700~~ **本轮不做**（用户裁决，自测后需要再改）；地图/出生维持现状 2200、1v1≈1300 / 1vN≈1500。已接受后果：移动察觉 1200m 下开局接触偏快（~15~30s），若实测过快，调节旋钮 = detectMove / 出生距离 / 地图扩大（C7 保留） |

## 1. 数据层：车辆标签

### 1.1 结构类型 `aiHull`（由 `cfg.casemate` 推导，可显式覆盖）

| 值 | 判定 | 行为含义 |
|---|---|---|
| `turreted` | 无 `cfg.casemate` | 全向交战，可动对动 |
| `casemate` | 有 `cfg.casemate` | 交战=摆整个车体；被绕侧=死穴；一切机动围绕「车头对敌」 |

特例：**M10** 结构归 `turreted`（有炮塔），角色归 `ambusher`（TD 心态）——结构与角色正交。

### 1.2 战术角色 `aiRole`（config 显式标注 + 缺省推导）

推导缺省：轻量高速（<20t 或推重比高）→`scout`；中坦 →`brawler`；重坦 →`anchor`；casemate 装甲厚/机动差 →`sniper`，其余 casemate →`ambusher`。

| 角色 | 核心行为 | dwell 距离/时间 | preferRange 系数 |
|---|---|---|---|
| `scout` | 前出侦查、保持 400m+、被确认即蛇形撤离、绝不站桩 | 1100m / 2s | ×1.2 |
| `brawler` | 中近距环绕机动、打了就换位、成群冲击 | 900m / 3s | ×0.7 |
| `anchor` | 正面摆角站桩、吸引火力、远距精度射击 | 1000m / 2.5s | ×1.0 |
| `ambusher` | 伏击 + shoot & scoot（开火后换位 15~30m） | 1100m / 2s | ×1.2 |
| `sniper` | 阵地化：选好射位基本不动，靠甲吃饭，严格伏击纪律 | 1200m / 2s | ×1.3 |

> dwell 距离为光学确认上限；v1.0 按玩家友好取向压低（德军远战压迫感基线 1100~1200m，原案 1500m），后续平衡只调 §13 旋钮。

## 3. 侦查/点亮对等模型（双方同一公式）

### 3.1 公平基准

AI 能力上限 = 玩家开同一台车、用同一瞄具，在屏幕上实际能看到、能打到的目标。玩家肉眼直接看渲染世界（无确认也能打），因此「AI dwell 确认才能打」是对玩家既有能力的对等化，不是给 AI 特权（【冲突 C6】裁决依据）。

### 3.2 第 0 层：硬上限

- `sightRangeHard: 1100 → 1600`（覆盖 fireContact 1400 与 dwell 1200 + 余量；超出即绝对安全区）
- ~~`mapSize: 2200 → 2700`~~ 本轮不做（裁决 #6）；地图/出生维持现状
- `fireContactRange: 1400` 维持（恰等于 TD 交战距离 → TD 开火必暴露疑似，反制循环成立）

### 3.3 第 1 层：察觉圈 → 疑似（不按车型，按目标行为）

| 目标行为 | 察觉距离（LOS 通畅） |
|---|---|
| 移动中（>1 m/s；尘迹/排烟/轮廓运动） | 1200m |
| 开火（现有 `onFire` 事件） | 1400m |
| 静止、引擎运转 | 900m（v1.1 自 700 上调：开阔地静止坦克远距同样可见，修 T1 接敌过慢） |
| 静止且软遮挡遮蔽 | 300m |

原则：**静则隐、动则现、打则露**。移动察觉 1200m 使双方出生直线开进约 25~40s 互相察觉（开局节奏由地图 2700 + 出生距离保证，见【冲突 C7】）。

### 3.4 第 2 层 A：自动确认圈（基础确认，无需努力）

- 基准：目标静止 500m / 移动 700m；软遮挡遮蔽封顶 300m（沿用现状）
- 角色系数：scout ×1.1 / brawler ×0.9 / 其余 ×1.0
- AI 难度系数 obsK：新兵 0.85 / 标准 1.0 / 王牌 1.1（替代现写死的 600/700/800 警戒圈）

### 3.5 第 2 层 B：光学确认（dwell，任务差异主战场）

- 触发：已有疑似接触（严格反应式，裁决 #2）→ 停车/稳住 → 炮口指向疑似扇形 → dwell 累积
- 扇形取定：中心 = `contactInfo.aimPos`（AI 侧含误差快照），扇形宽度随 `errVec` 大小收敛（连续开火→扇形收窄）
- 效果：该扇形内确认能力延伸到角色 dwell 距离（§1.2 表）；dwell 完成 → 转确认（level 2）
- 打断：受击（位移规避）、目标热度消失、doctrine 不 dwell（苏军 brawler 直接推进）
- 超时：4s/扇形未完成 → 扇形冷却 30s，转下一热度点
- 玩家侧：沿用现有 `playerDwell` 机制，上限放开到本车角色 dwell 距离（现卡 1100）
- 玩家信号链：AI dwell 期间玩家 HUD 显示 CONTACT（疑似）、dwell 完成升级 SPOTTED（确认）——「换位窗口期」对玩家可见，反制时机明确（沿用 `updateExposure`，UI 零改动）

### 3.6 目标修正 `tgtK`（乘在确认距离上）

| 目标状态 | 系数 |
|---|---|
| 开火后 3s 窗口内 | ×1.5（与 1400m 疑似事件并存） |
| 重型/大型车体 | ×1.15 |
| 低矮车体（车高 <2m：jpz4、猎豹、黄鼠狼） | ×0.85 |
| 静止 ≥5s（埋伏态，裁决 #8） | ×0.8 |
| 软遮挡后 | 封顶 300m |
| hull-down（车体被地形遮） | ×0.5 |

### 3.7 观察者修正 `obsK`（乘在确认距离上）

- 车长：伤 ×0.8 / 亡 ×0.5；通讯员：伤 ×0.95 / 亡 ×0.85（**启用 `spotMult()` 死代码**）
- 观瞄模块：受损 ×0.7 / 损毁 ×0.4（新接线，「打瞎战术」成立）
- 综合 obsK 设下限 0.25（防叠加成全瞎，【冲突 C16】）

### 3.8 扇形视野（方向性）

- casemate：前向 ±30° 全距，侧后 ×0.5
- turreted：目标在炮塔朝向 ±60° 内确认延迟 0.5s，其余方向 1.2s（先发现后转塔）
- 不做得过瞎的补偿：巡逻扫掠频率提高、多车排级扇区拼接互补、被绕 panic（§5.4）

### 3.9 确认后维持与降级

- 沿用：LOS 保持 + 硬上限内持续跟踪；断视线 3s（`spotHold`）→ 失联 7s
- 新增：目标进入软遮挡 **且静止 ≥5s（埋伏态）** 后，下一检测周期按遮蔽规则重评（丛内静止最多维持 300m 逻辑）——杜绝「确认一次永久透视灌木」；移动目标过灌木不触发重评（防减速过丛即掉确认的抖动）

### 3.10 开火暴露（双方统一）

- 1400m 内：疑似（快照）；LOS 且在各自确认圈内 → 直接确认
- AI 侧快照：40~80m 误差、软遮挡 ×1.5、连续开火 ×0.5/发 收敛（<8m 视为锁定）——沿用
- 玩家侧快照：精确位置（裁决 #7），`farSnapshotError` 开关默认关

### 3.11 性能预算

- LOS 地形采样 4m 步进在 1600m 需 400 点/对；检测周期 0.3s、敌对对 ≤10 → 每 tick ≤4000 采样，可接受
- 距离分级：`losDetail` 距离 >800m 时地形步进放宽到 8m（精度损失对远距判定无感）
- 阵位评分采样点（§6.2）带缓存：同一评分请求 2s 内复用结果

### 3.12 玩家侧变化点清单（裁决 #5 范围澄清）

点亮公式是双方机制，重写后玩家侧数值面必然变化，集中登记（【冲突 C20】）：

| 变化点 | 现状 | 新模型 | 性质 |
|---|---|---|---|
| 玩家 dwell 上限 | 1100m 硬卡内均可 | 按本车角色（brawler 900 ~ sniper 1200） | 中坦 dwell 略降、TD 略升——车型选择产生玩法差异 |
| 玩家自动确认圈 | 静止 500 / 移动 700 | ×角色系数（brawler ×0.9 / scout ×1.1） | 微调 |
| 玩家作为目标的 tgtK | 无 | 埋伏 ×0.8 / 开火窗口 ×1.5 / 低矮车体 ×0.85 等 | 对等核心：蹲坑更安全、开火更危险 |
| 玩家观察通道 UI | ▼/◆/? 标记 | 不变（C12） | 无感 |

## 4. 特殊开火规则

### 4.1 伏击纪律（ambusher/sniper）

确认点亮也不急于开火：目标进入射界 ±arc×0.8 扇面且在 fireRange 内才打（casemate 防止为开火转向暴露）；sniper 不开排战第一枪——等玩家注意力被 anchor 吸引后再开火（位置就是生命）。**独狼（n=1）时延迟开火规则不生效**：没有 anchor 可等，sniper 按伏击纪律直接打。

### 4.2 shoot & scoot

按 `scootChance`：开火后**先直线倒车**（车头保持朝敌、维持射界威慑）→ 退出 10~15m 后转向新阵位 → 到位 yaw 对轴，全程 15~30m。开火暴露 1400m 规则下换位真实有效（玩家只有快照）。casemate scoot 期间短暂失射界是刻意代价（【冲突 C14】）。

### 4.3 苏军盲射压制（裁决 #3）

- 触发：doctrine=ru、疑似接触距离 <800m、无确认目标
- 规则：朝疑似扇形开火，射速 3/4（v1.1 调校，原半速）、散布 ×2，每个疑似周期最多 2 发（防弹药浪费，【冲突 C5】）
- 窗口：苏军光学确认 900m、自动圈 ~600m → 盲射主要覆盖 500~800m 接近段

### 4.4 掩体遮挡与 HE 拆掩体

- 沿用：弹道被挡不开主炮；王牌概率换 HE 拆
- 新增防挠痒：连续 2 发被掩体吃掉 → 强制转移/包抄（§8 表）

### 4.5 火线纪律（友军误伤防护，多车必需）

多车包抄/线列推进后必然出现队友进入炮线的情况，新增开火前检查：

- 炮线 ±3° 锥内存在友军、且友军距离 < 目标距离 → 不开火，横向转位（strafe 出射界后再评估）
- 盲射（§4.3）同样检查；MG 不检查（无穿透伤害）
- 检查频率：每次开火决策时一次（射线-友车圆柱快速判定，代价可忽略）
- 【冲突 C21】登记：宁要「不开火转位」的保守，不要拟真 TK——游戏内误伤只产生挫败没有战术价值

## 5. 排级大脑 `PlatoonAI`

### 5.1 角色分配

按 `aiRole` 自动编排：scout 前出 100~150m；anchor 居中；sniper/ambusher 占侧后伏击位；brawler 机动预备队。n=1 时退化为独狼（§7.3）。新兵档：无排级（各车独狼）。

**任务替补链（无侦查车编队）**：搜索/前出是**任务分配**，不与 scout 角色绑定。指定顺序：scout → brawler（取最机动者）→ anchor → ambusher → sniper。按编队构成的打法：

- 重坦编队（如 3 辆虎式/IS-2）：线列交替掩护跃进（bounding overwatch）——一辆停车瞄准掩护，其余前进 100~150m 后换位；德军交错跃进、苏军全员同推。
- 歼击车编队：L1 由替补链指定的搜索担当（取相对最机动者）离位沿 POI 搜索，其余固守阵位掩护；L2 起整体向下一预勘阵位缓慢转移。**dwell 仍仅限疑似扇形**（裁决 #2 不变：静态搜索靠机动不靠空扫扇面）。
- 原则：任何编排在 L1 都必须产生「会暴露自己的搜索动作」，不因缺侦查车而停摆（【冲突 C19】）。

### 5.2 阶段式交战流程

1. **行军**：楔形/纵队，scout 前出，编队槽位间距 ≥80m
2. **戒备**（任一车 suspected）：排停。德→就近伏击扇面、电台静默；苏→全队转向提速
3. **确认**（spotted）：anchor 正面摆角吸引；flanker 60~90° 包抄，到位后总攻；sniper 延迟开火（§4.1）
4. **失联**：anchor 留守威慑，flanker 按速度矢量外推 15s 到拦截点，scout 沿热度迹线搜索
5. **减员/重创**：德→交替掩护撤退（一辆倒车时另一辆瞄准掩护）；苏→不退

### 5.3 开火时序

排级错开开火窗口（王牌：anchor 开火后 2s 内 flanker 不开火，保持压力连续）；某车射界被挡/被绕 → 交还排级重排，不死守分配。

### 5.4 通讯规则

- 电台沿用 2~4s 延迟，但**广播扇区而非精确点**（防全员挤同一坐标）
- 被绕侧 panic：原地枢轴+倒车甩车头对威胁 + 电台呼救
- 协同约定超时替补：flanker 8s 未到位 → anchor 自主行动（防协同死等）

### 5.5 怀疑度地图（排级共享）

- 200m 网格热度图，时间衰减；事件注入：开火声、被击弹向扇形、电台扇区、履带痕（`trackmarks.js` 数据接入）、灌木扰动（`hedgefield.muzzleShake` 同源事件）
- 用途：搜索排序（新事件优先）、dwell 目标选择、失联拦截点计算
- **不注入玩家真实坐标**——热度全部来自可解释事件
- **与 visibility 的分层**：单体认知等级仍由 visibility/contactInfo 唯一裁决；suspicion 是排级共享的「搜索建议层」，事件源 = visibility 等级跃迁（0→1）+ `onFire` + `notifyContact` + 穿行/履带点。suspicion **不反写**认知等级——避免两套真相

## 6. 个体行为状态机

### 6.1 状态集与铁律

状态：`search / alert / engage / relocate / evade / recover`。
**铁律：任何状态必须带超时出口 + 超时默认动作**（超时表见 §8.2）。

### 6.2 阵位系统（独立模块，裁决 #4）

阵位 = 掩体（挡视线）+ 射界（预瞄朝向可达）+ 撤离路线（倒车路径净空）三合一评估：

- 采样：3 半径环（15/37.5/60m）× 8 方向 + 任务朝向约束（casemate 必须能 yaw 对轴）
- hull-down 位：双高采样——`canSeePoint` 炮塔顶高可见 且 车身高不可见（现有 LOS 双高机制支持）
- 评分 = 遮蔽分 + 射界分 + 撤离分 − 距离偏差 − 自车机动成本；切换滞后 1.5 分（防 A↔B 振荡）
- 共用方：casemate 伏击位、turreted 卖头位、撤退链节点

### 6.3 casemate 专属

- 到位先 yaw 对预期交战轴再熄火；伏击纪律（§4.1）；scoot（§4.2）
- **alert 态先摆车体**（v1.1 用户实测修复）：疑似扇面超出射界 ×0.8 → 原地枢轴转向扇面再细搜——「听到侧后动静先调车身」
- 被绕 panic：枢轴+倒车甩头，呼电台；**甩头为最高优先级机动（清 scoot/dash 抢权，v1.1）**；角速度追不上绕行玩家时允许「倒车拉开重置角度」，被绕死是史实死穴、不做无敌补偿

### 6.4 turreted 专属

- 摆角对射泛化到标准档（王牌加角度优化/换向频率）；`tiltPref` 按 §1.3
- 短停射击保留王牌独占（补 `stopMaxT` 接线，§8.2）
- `movingFire`（m4a3 稳定器）：行进开火散布门槛放宽一档

### 6.5 撤退链

evade 从「倒车蛇形」升级为「沿阵位链交替撤退」：2~3 个连续阵位逐段倒车；doctrine=de 时队友掩护。开阔地零收益计数 → 背水一战（§8.2）。撤退目标点 clamp 在地图 bound 内（AI 不出场，防「追不上逃敌拖时限」）。

### 6.6 火力丧失降级

炮闩损毁且修理耗尽 → 不再等死：德/美转「游走吸引」（在队友火力轴附近机动诱敌），苏军卖命冲锋。**优先级高于 evade/背水一战**——开不了火的车不触发「背水一战转 engage」（没意义），直接走本降级。

### 6.7 消耗品/修理

沿用：起火 0.8s 灭火；断履带/模块损在脱战（无接触或 >260m）时读条修理；被击穿打断修理（`tank.js:1031`）。新增：玩家进入 260m 时中断修理倒车。

## 7. 独狼与多车差异

### 7.1 多车（1vN）

- 编队槽位：排级分配扇区 + 间距 ≥80m；分离转向（boids separation 并入 `_avoidSteer`，替代/补强现有避障）
- 扇区拼接互补（补偿 casemate 侧后瞎，【冲突 C4】）
- 协同超时替补（§5.4）、开火时序（§5.3）

### 7.2 独狼（1v1）

排级 n=1：角色融合降级 = doctrine 底色 + 本车角色，不搞分身；节奏总监对 n=1 同样生效（§8.1）。

### 7.3 新兵档

无排级、无 doctrine、无 dwell、obsK 0.85、反应 3.0s——即「会动的靶子」档，行为接近现行标准档下限。

## 8. 可靠性设计（僵局/卡死/假死/死循环）

### 8.1 节奏总监 Pacing Director（防全局僵局）

删除 patrol 全图感知后，这是全局节奏的保证（原全图感知实质是隐性防僵局机制）：

| 升级 | 触发（无确认接触） | 动作 |
|---|---|---|
| L0 | — | 正常搜索/伏击/推进 |
| L1 | 45s | 侦查单元沿热度 POI 链主动搜索——动则暴露，玩家获得射击窗口；无侦查车时按 §5.1 替补链指定搜索担当，TD 编队固守掩护 |
| L2 | 75s | 排占领地图控制点，压缩玩家可隐蔽区；苏军全线推进 |
| L3 | 105s | 梳篦式扇区推进（德分片细搜/苏平推）；**L3 持续 45s 仍无接触 → 推进敌整备区**（轴线上越过中心 ~750m 的点——对称知识：敌出生区方向，非玩家实时坐标；到达后以敌半区节点继续梳篦） |
| 兜底 | 600s 时限 | 时限判定（玩家无击杀按现行规则判负/平局） |

表注：doctrine=ru 时 L1 合并执行 L2 行为（全线推进，不做单兵搜索）——符合苏军「不 dwell 直接推进」底色。

与裁决 #2（严格反应式）的关系：反应式约束的是**火控**（不预瞄未来路线），节奏总监约束的是**战略机动**（无信息时的搜索义务），两者不冲突（【冲突 C1】）。

### 8.2 状态超时表（铁律落实 + 现网漏洞修复）

| 状态 | 超时 | 默认动作 | 现网漏洞（引用） |

| alert 戒备 | 疑似消退 + 反应延迟 | 转 flank/搜索 | — |
| dwell | 4s/扇形 | 扇形冷却 30s | — |
| cover-holding | 装填上限+2s 未就绪 | 火力丧失降级 §6.6 | `ai.js:266-271` 等 readyToFire 可永远等 |
| peek 到位 | 6s 未开火（含被挡） | 强制 relocate | `ai.js:272-285` 到位被挡永不开火永不转移 |

### 8.3 物理卡死升级阶梯

- L1：现有 unstick（倒车 1.5s + 22m 切线绕行点）
- L2：60s 内 3 次 L1 → 朝地图中心 60m 开阔点强制 repath
- L3：L2 无效 → 目标点拉黑 60s，改执行排级任务（修复：绕行点被堵原地 jiggle、AI 互顶/残骸推挤）

### 8.4 振荡抑制

- 决策提交期：同类决策 4s 内不得重掷（`_sameCount` 泛化）
- 切换滞后：新阵位评分须超当前 1.5 分
- evade 统一冷却（修复平原无限蛇形）

### 8.5 看门狗 Watchdog（独立于状态机的兜底）

1. 单车：有油门意图 5s 无位移 → 强制 L2 repath；交战 20s 零战果 → 强制转移
2. 排级：45s 无接触 → 节奏升级（§8.1）
3. 全局：soak 场景必须 600s 内出结果
约束：watchdog 只下达移动/转移指令，不瞬移、不改认知等级（【冲突 C11】）。
