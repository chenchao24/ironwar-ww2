# 焊死轮系切割手册（负重轮无独立元件的坦克模型接入指南）

> **由来**：2026-09-13 虎王 Tiger II（`tankModel/pz.kpfw._vi.glb`）接入时总结。
> 该模型负重轮/主动轮/诱导轮全部焊死在 `Object_13/15` 两个网格里，无法像其他车一样按节点名分组旋转。
> 本文档记录完整的离线切割工作流、每一道精滤的判别依据与踩坑史，供后续同类模型直接复用。
> **主脚本**：`scripts/split-wheels-kt.js`（@gltf-transform，Node 直接跑）。
> **配套**：`glbview.html`（隔离渲染）、`scripts/check-tiger2-*.js`（渲染复核）、`scripts/verify-tiger2.js`（游戏内断言）。

---

## 一、什么情况下需要这套流程

| 情况 | 处理方式 |
|---|---|
| 轮子有独立节点/元件（md 标注里有 wheel 类原件） | **不需要**。config `parts.wheels` 直接列节点名 |
| 轮子焊死在某个大网格里（md 标注没有轮子原件，整车只有几个 Object） | **用本流程**：离线把轮子三角面切成独立网格，游戏端按 `wheelXxx` 节点名分组 |

游戏端机制（`js/tank.js`）：`parts.wheels` 列出的每个节点，按 **bbox 中心建枢轴 Group** 绕 X 旋转，转速 = 车速 / (bbox 高度/2)。
**因此轮网格必须满足两个硬指标**：① 几何就是一个圆（不能带摇臂/挡泥板/支架）；② bbox 中心 ≈ 真实轮心（偏心 5cm 以上转动可见晃动）。

## 二、总流程

```
源模型 (tankModel/xxx.glb)
  → node scripts/split-wheels-kt.js        # 离线切割 → model/tiger2.glb
  → node scripts/check-tiger2-wheels.js    # glbview 隔离渲染复核（必须看图！）
  → js/config.js 配置 parts.wheels / track / hullMg ...
  → node scripts/verify-tiger2.js          # 游戏内：轮组数/履带/行驶断言
```

### 脚本结构（split-wheels-kt.js）

1. **材质转换**：老模型多为 KHR_materials_pbrSpecularGlossiness，three 新版不支持 → `metalRough()` 转换，否则整车无贴图。
2. **世界坐标**：所有判定在世界空间做（`worldMat()` 沿父链累乘矩阵）；生成的轮节点挂回**同一父节点 + 同一局部矩阵**，世界变换不变。
3. **三类轮子，三种切法**（关键决策，见下）。

---

## 三、核心决策：先摸清轮系结构，再选切法

**不要上来就切**。先跑结构分析（参考 `scripts/analyze-kt3.js`）：把轮带三角面（`|x|>1.25, y<1.4`）按**共享顶点连通分量**聚类，打印每个大分量的 bbox 和中心。虎王的实测结构：

| 分量 | 位置 | 是什么 | 切法 |
|---|---|---|---|
| n=286，x[1.48,1.65]，5 组 z 中心 | 外排 | **外排 5 负重轮/侧**（独立几何岛） | **整岛抽取**（最优，见 §4） |
| n=92，x[1.35,1.43]，同 5 组 z | 外排轮侧壁 | 同上，并入同轮 | 整岛抽取 |
| n=64，x[1.13,1.33]，4 组偶数 z | 内排 | **内排 4 轮/侧**（交错） | **不切！留车体静态**（见 §5） |
| n=322+180，z≈-2.52 | 车尾 | 主动轮（与摇臂/挡泥板顶点相连） | 圆盘分类+精滤（见 §6） |
| n=640+360，z≈3.00 | 车头 | 诱导轮（与挡泥板贴近） | 圆盘分类+精滤（见 §6） |

### 切法选择原则

1. **能用整岛就不用圆盘**：轮子如果是独立连通体（与车体/相邻轮不共享顶点），整岛抽出 = 零误伤，贴图、圆度 100% 保留。
2. **交错轮（内外两排重叠）只切外排**：内外排在同一 (z,y) 圆盘内半径重叠，任何按质心的空间分类都必然互切，内侧轮贴图必坏。内排被外排遮挡大半，**静态不转的观感远好于切坏的旋转**（用户实测确认）。
3. **与车体共享顶点的轮（主/诱导轮常见）才用圆盘分类 + 精滤**。

## 四、切法 A：连通岛整抽（外排轮，首选）

```text
池 = 剩余三角面中 |x|>1.28 且 cy<1.4 的（轮带外层）
按共享顶点建邻接 → 连通分量
分量 >40 面 且 bbox 中心匹配轮位（hypot(Δz,Δy) < 0.4）→ 整岛抽出为轮网格
其余（内排轮、翼子板支架、碎弧）留车体
```

- 轮位中心从结构分析实测（虎王：z=-1.94/-0.90/0.13/1.16/2.19，y=0.47）。
- 侧别按分量质心 x 符号分 R/L。
- **注意**：碎弧/小零件岛（<40 面）不切；中心不匹配的岛（挡泥板支架再大）也不切。

## 五、切法 B：不切（内排交错轮）

内排 4 轮留在原网格里，随车体静态。config 的 `parts.wheels` 只列切出来的轮节点。
**不要为了让内排也转而硬切**——虎王第一版 22 轮全切，内排贴图撕裂、外排被邻轮碎片污染不圆，行驶观感反而差。

## 六、切法 C：圆盘分类 + 五重精滤（主动/诱导轮）

适用于轮子与挡泥板/摇臂/车体**共享顶点**、无法整岛分离的情况。

### 6.1 粗切：轮心圆盘分类

```text
x 双带：|ax-1.04|<0.11（内环带）∪ |ax - 轮实测x|<0.30（外环带）
(z,y) 圆盘：dist((cz,cy),(w.z,w.y)) / w.r < 1.25 → 最近轮心胜出
```

- 轮心用**环带得分精修**（`refine()`）：轮圈带 [0.25,0.45]r 内点多、外带 [0.45,0.55]r 点少的 (z,y) 最优。
- **坑 1**：精修的 y 搜索下限别卡太死。虎王初版 `yLo=0.85` 把主动轮心顶高 0.3m，切割盘直接扣住挡泥板。给足范围（0.5~1.15）让数据说话。
- 粗切放宽到 1.25r，收进来的杂质交给精滤，宁宽勿漏。

### 6.2 精滤一：连通分量 BFS + 法线连续判据

```text
种子：轮圈带 [0.22,0.40]r 内的三角面
BFS 扩展条件（同时满足）：
  ① 共享顶点（key = 坐标保留 3 位小数）
  ② 两面法线点积 > cos60°（法线由顶点叉积现算，不依赖 NORMAL 属性）
```

- **坑 2**：挡泥板与轮缘在源模型里**共享顶点**，纯顶点邻接会把整片挡泥板判进轮桶。法线连续判据在板/轮交界处（二面角 ~90°）断开。
- **坑 3**：挡泥**弧板**与轮同心、法线连续渐变，①②都切不断 → 加**顶点半径帽**：BFS 不扩展到任一顶点超出 1.2r 的三角面。注意帽子必须按**全部顶点**判（板子三角形巨大，质心可能在帽内）。

### 6.3 精滤二：叶剥离（吃细长碎条）

```text
迭代 ≤12 轮：剥掉与连通体仅 ≤1 条共享边的三角面
```

- 挡泥皮碎条、切边毛刺的特征是"挂在轮缘上"，悬挂连接；轮体三角面致密互连（≥2 条共享边）不受影响。
- **坑 4**：宽板（≥2 边相连）剥不动 → 靠 6.4/6.5 的几何特征兜底。

### 6.4 精滤三：长边竖板剔除

```text
剔除：最长边 > 0.40 且 rc（质心半径）> 0.30
```

- 实测依据：挡泥皮竖板三角形边长 0.42~0.43、rc 0.34~0.40；轮体 legit 大三角面（轮毂盘面）边长 ≤0.39 且 rc ≤0.26。
- **方法论**：别猜阈值，先跑分析脚本（`scripts/debug-ws*.js`）把"杂质 vs 轮体"的边长/半径分布打出来，找天然分界。

### 6.5 精滤四：摇臂尖刺剔除（后轮主动轮常见）

```text
剔除（仅主动轮）：rv（最大顶点半径）> 0.42 且 |x| ∈ (1.37, 1.57)（两齿环之间）
```

- 悬挂摆臂与轮毂共享顶点、法线连续，会随 BFS 混进来，把 bbox 中心顶偏 **8cm**（旋转肉眼可见晃动——用户实测发现）。
- 判别关键：轮上能伸出轮缘的只有齿尖，齿尖必在齿环 x 位；摇臂在两环之间。先弄清"伸出物 vs 轮体"的 x 分层再下刀。
- **排查法**：用户报"圆心不对"→ 先量轮网格 bbox 对中性（`z范围/y范围`是否关于轮心对称），不对称就隔离渲染找突出物，再分析其几何特征定判别式。

### 6.6 外圈碎条兜底

```text
剔除：rc > 0.43（实测轮体全部 ≤0.42）
```

最后一张安全网，清掉穿过所有精滤的同心弧板碎条。

## 七、附属切割：Object_11 类多元件合并节点

虎王的 `Object_11` 把车顶高射机枪和车体前机枪合并成一个元件。按**质心世界坐标**直接切：

```text
质心 y > 2.2 → 车顶机枪 → 新节点 roofMg（config parts.hidden 隐藏）
其余 → 留 Object_11 → config parts.hullMg（F 键前机枪）
```

- 两挺机枪在 y 分布上是两个分离簇（1.5~1.7 vs 3.1~3.4），一刀切即可；合并元件先打 y/z 直方图找分离面。
- 拆分节点与源节点**同父同矩阵**，游戏端无感知。

## 八、config 接入要点（js/config.js）

```js
parts: {
  wheels: ['wheelR1','wheelR3',...,'wheelRS','wheelLS','wheelRI','wheelLI'], // 只列切出来的
  hullMg: ['Object_11'],
  hidden: ['Object_6', 'roofMg'],
},
trackScrollAxis: 'y',      // 履带 UV 纵向：量 vRange/uRange 跨度，跨 10+ 格的是纵向
trackScrollFlip: true,     // 方向判据见下
hullMgArc: 0.26,           // 前机枪射界 ±15°
```

### 履带滚动方向判据（免试错）

量履带网格**底段**（y 最小 15% 顶点）的 `dv/dz`（或 `du/dz`）符号：

- 前进时 offset 递增 → 贴图特征向低 UV 端移动；
- 虎王/T-34 底段 `dv/dz<0`（V 车尾高、车头低）→ offset 递增 = 底段贴图向车头滑 = **倒车样式** → 必须 `trackScrollFlip: true`。

先算后配，不要靠肉眼猜（T-34 曾因此返工两次）。

### 轮子旋转方向

模型 `+z` 朝前（或经烘焙转为 +z）时，`rotation.x += speed*dt/radius` 方向天然正确，无需 flip 开关。

## 九、验证清单（每步都不能省）

1. **隔离渲染**（`glbview.html?glb=...&only=wheelXX`）：
   - 每个切出的轮子单独看——必须是"一个圆"，无平板/尖刺/弧板；
   - 正侧面 + 斜视 + 俯视各一张（有些碎片只在特定角度可见）。
2. **bbox 对中性**：轮网格 z/y 范围关于轮心对称（偏心 >5cm 必晃）。
3. **整车渲染**：前/后/侧三视角，确认被切部位无缺口（剔下的碎片必须退回车体）。
4. **游戏内断言**（`scripts/verify-tiger2.js`）：
   - 车库：`wheelGroups.length` = 预期数、`trackMaterials` = 2、`hullMgGroup` 存在；
   - 行驶 3s：轮转角非 0、履带 offset 变化方向正确、0 控制台错误。
5. **真人上车**：开一圈看轮转/履带/机枪——数据全对也可能有观感问题（摇臂偏心就是这么发现的）。

## 十、踩坑史速查（症状 → 根因 → 解法）

| 症状 | 根因 | 解法 |
|---|---|---|
| 轮桶里有一整片挡泥板 | 轮心精修 y 下限卡死，轮心偏高 0.3m | refine 搜索范围放开 |
| 精滤只退 25 面，板子还在 | 挡泥板与轮缘**共享顶点**，BFS 当成一体 | 加法线连续判据（<60°） |
| 弧板法线渐变，仍切不断 | 弧板与轮同心 | 顶点半径帽 1.2r |
| 板子质心在帽内 | 三角形巨大 | 帽按全部顶点判，不按质心 |
| 细长碎条剥不掉 | 宽板 ≥2 边相连 | 叶剥离只管悬挂 ≤1 边的；宽的走长边剔除 |
| 行驶内轮贴图撕裂 | 交错内外排圆盘互切 | 内排不切，静态留车体（§5） |
| 轮转起来圆心晃 | 摆臂碎片顶偏 bbox 8cm | 按 x 分层剔除两环间尖刺（§6.5） |
| 前进时履带像倒车 | UV 绕向反 | 量底段 dv/dz 符号定 flip（§8） |
| 履带贴图横着滑 | 滚错轴 | 量 vRange/uRange 跨度定 trackScrollAxis |

## 十二、变体案例：费迪南/猎豹（2026-09-18）——轮在独立节点内、但一轮=同心环多分量

与虎王（轮焊死在车体大网格）不同，这两辆车的负重轮在 **md 标注的独立轮件节点**里，但每个节点把多轮+多圈焊在一起，且**一个轮被拆成多个互不连通的同心环分量**（外胎环 / 内环 / 轮毂 / 螺栓 / 主动轮齿圈分属不同连通岛）——整岛抽取只能拿到一个环。切法改为（`scripts/split-wheels-ferdjag.js`，双车参数化）：

1. **满盘分量发现轮心种子**：y/z 跨度 ≥ discSpan（0.5~0.55）的连通分量是完整轮盘，其 bbox 中心即轮心；同中心多分量归并为一个种子。内排偏移弧（跨度不足）不会成为种子。
2. **最近锚点归桶**：所有分量（含螺栓/齿圈小件）按 (z,y) 中心距最近种子归桶——road 半径 0.3（偏心 >0.16 的非满盘弧留静态），主动/诱导轮放宽到 r+0.15（齿圈要跟着转）。
3. **road 桶按 z 排序命名 wheelR1..N**（键含 z 防串桶）；生成节点同父同矩阵。
4. **主/诱导轮锚点先量再填**：从分量分析里读（费迪南后主动轮 -2.78/前诱导轮 2.95；猎豹前置主动轮 2.83/后诱导轮 -2.47——底盘布局不同，别抄）。

**履带新坑**：猎豹履带是**单节点含双侧**——两侧 UV 绕向必须分别测（corr(z,v)），本例双侧同向只设 flip 即可；若镜像（如 IS-2 Object_28/40）需离线翻 V。**收尾**：费迪南内排偏移弧、猎豹交错内排底弧、以及猎豹左侧 z≈1.0 一轮（盘跨度略小于阈值）留静态——先跑 `analyze-ferdjag.js` 打印分量表再定 discSpan，宁少切勿切碎。

### 12.1 悬挂混桶三连坑（2026-09-18 用户实测反馈：轮转带动扭杆/连杆、圆心偏）

中心距归桶会把**扭杆/摆臂/张紧臂**吸进轮桶（它们的分量质心恰好落在轮心附近），bbox 中心被顶偏 → 轮转晃 + 连杆跟着转。三道过滤（`split-wheels-ferdjag.js` 已实现）：

1. **x 向跨度帽**：轮体是窄盘（spanX ≤0.26~0.35），横穿车体的扭杆 spanX >0.45 直接剔除；
2. **逐顶点半径帽**（§6.2 同款）：顶点 (z,y) 半径 >1.25×盘半径剔除。**必须逐顶点**——用 bbox 角点测距会把环形件的"空角"算进去（环 bbox 角半径 0.49 > 实体 0.35），整圈被误删（踩过：轮只剩 286 面）；
3. **S/I 附加 z 门**：张紧臂是**链式小件**（每段 n≈16、径向都在帽内），只有沿 z 超出**盘体半深**才露馅——门宽用各锚点的盘深参数（zGate），猎豹诱导轮盘深仅 ±0.31 而 ring 半径 0.44，统一用 ring 半径门就切不断。**坑中坑**：锚点参数转种子时必须逐字段拷贝（漏拷 zGate → 门静默失效，三轮输出一模一样才发现）。

验收以**输出 GLB 的逐轮 bbox 对中性**为准（measure 脚本 world 坐标）：本例最终全部 ≤0.03m。注意诊断脚本读原始 accessor 时坐标系是节点矩阵**前**的（Sketchfab 包裹带轴旋转，y/z 会互换），必须走 worldMat 变换。

## 十一、复用清单（接下一辆焊死轮系的车）

1. 复制 `split-wheels-kt.js` → `split-wheels-<车名>.js`，改 SRC/OUT。
2. 先跑结构分析（连通分量聚类），确认轮系布局，按 §3 选切法组合。
3. 轮心/轮位用脚本实测，不要抄虎王的数。
4. 每道精滤的阈值（半径帽、长边、x 窗口）按本车实测分布重新标定——**先打分布再定阈值**。
5. 走 §9 验证清单，全部过了再交付。
