一、解压与启动（必看）
═══════════════════════════════════════

1. 解压 IronWar3-绿色版.zip 到任意位置（路径别太深，别有中文特殊符号更稳）
2. 进入解压出的 IronWar3 文件夹，双击【启动游戏.bat】
3. 稍等 2~5 秒，浏览器会自动打开游戏（推荐 Chrome / Edge）
4. 若浏览器没自动打开，手动打开浏览器访问：http://localhost:8081

注意：
・若杀毒软件/Windows 防火墙弹出提示，选择"允许"（包内 bin\node.exe 是官方
  Node.js 绿色运行时，用于本地起服，无毒）
・玩完关闭：关掉启动时留下的黑色命令行窗口即可（浏览器页面可随手关）
・若提示端口被占用：说明你电脑上已有游戏在跑，先关掉旧的黑窗口再启动

═══════════════════════════════════════
二、游戏流程
═══════════════════════════════════════

封面（点击任意处进入）→ 主菜单 → 车库 → 开始战斗 → 结算

车库界面可以选：
・你的坦克（左右翻页或下拉直选，24 辆史实坦克：虎式/虎王/黑豹/谢尔曼/
  潘兴/T-34/IS 系列/费迪南/猎虎/克伦威尔……）
・敌方编队：逐槽指定车型或随机，最多 1v5
・AI 难度：新兵 / 标准 / 王牌
・固定阵营开关：开了之后敌人只会是敌对阵营（轴心德 ↔ 同盟美英苏）
・地图选择（见第三章）

三、操作说明
═══════════════════════════════════════

【驾驶】
  W / ↑          前进（按住）
  S / ↓          倒车
  A D / ← →      转向
  空格           刹车

【炮术】
  鼠标           转炮塔 / 瞄准
  左键           开炮（主炮）
  右键           开 / 关瞄准镜（开镜后才是精确射击）
  Shift          瞄具倍率切换（开镜状态下，部分车双档）
  滚轮           第三人称视角拉近拉远
  1 / 2 / 3      切换弹种：AP 穿甲弹 / HE 高爆弹 / APCR 次口径穿甲弹
                 ※ APCR 只有部分车有（穿深高、后效低、备弹少）

【机枪】
  中键按住       同轴机枪连发
  F 按住         首上前机枪（装备车限定，射界内自动瞄准）

【观察】
  Q              车长望远镜（侦查视角）
  C              自由观察视角开关
  右上角小地图   战场态势（道路/建筑/敌情标记）
  左下车姿显示器 车体姿态俯仰/侧倾指示

【战场生存】
  R              修理（读条；断履带/坏模块后使用）
  T              灭火器（起火后用）
  Esc            暂停

【击毁判定——本游戏没有血条！】
  坦克被击毁的条件是：乘员全灭 / 弹药殉爆 / 起火烧毁。
  打不穿就是打不穿——瞄弱点、拉近距离、换 APCR、绕侧后。
  HE 打不穿装甲也有溅射/震伤价值，对着脸糊可以坏炮坏观察窗。
  你自己被打惨了会自动弃车（弃车=败）。

四、关卡（地图）说明
═══════════════════════════════════════

【库尔斯克 · 1943 —— 东欧平原】
・地形：开阔草原 + 交叉土路 + 零散村落 + 巨石掩体
・地软：野地略减速，土路更顺
・打法：远距对射图。抢巨石/村落当掩体，利用缓丘反斜面伸缩炮，
  远距离先望远镜确认目标再开镜细瞄

【诺曼底 · 1944 —— 树篱田】
・地形：bocage 树篱田块 + 欧洲小镇（约 70 栋可破坏建筑）
・树篱是软遮挡：挡视线不挡炮弹——可以"隔篱盲打"，也可以直接撞穿
・打法：逐田格推进，小镇巷战格外凶险；清晨低阳，注意逆光方向

【阿登森林 · 1944 —— 雪林山地】
・地形：积雪针叶林 + 山脊谷地 + 中心村 + 浅雪溪；大雾（视距约 600m）
・积雪减速越野；压实雪路/林道更快——走路就是比越野快
・炮弹可以穿树（树干只会被削断，炮弹照样飞），别指望树林挡炮弹；
  但林子挡视线——雾 + 林 = 遭遇战贴脸
・打法：控路 + 占村；林缘伏击；巨石是雪中真掩体（5 发才炸碎）
・彩蛋氛围：战场飘雪；双方坦克都是冬季白洗涂装（掉漆斑驳的史实样式）

五、常见问题
═══════════════════════════════════════

Q: 双击 bat 没反应 / 闪退？
A: 右键 bat → 以管理员身份运行试一次；还不行检查解压是否完整
   （IronWar3 文件夹里应有 bin、js、model、index.html 等）

Q: 浏览器打开白屏 / 一直转圈？
A: ① 确认黑窗口还开着（那是服务器）② 换 Chrome/Edge 最新版
   ③ 刷新页面试试 ④ 电脑太老不支持 WebGL2 的话玩不了

Q: 画面卡顿？
A: 主菜单 → 设置 → 画质调低一档；关掉其他占资源的程序

Q: 想改键位/音量/画质？
A: 主菜单 → 设置（音量/画质/BGM 都在里面）
